Размещение доминошки (Task1)

Дано клетчатое поле размером n × m. Некоторые клетки поля заняты. Определите, сколькими способами можно положить доминошку размером 2×1
2×1 (её можно также повернуть на 90 градусов), так, чтобы ни одна клетка доминошки не располагалась в занятой клетке.

Формат ввода
Первая строка содержит два целых числа n и m (1≤n,m≤1000) — размеры таблицы.

Каждая из следующих n строк содержит по m символов. Символ "#" означает, что соответствующая клетка занята, а символ "." — что она свободна.

Формат вывода
Выведите число способов размещения доминошки.

Пример 1
Ввод
2 3

...

...

Вывод

7


Пример 2
Ввод

3 4

..#.

#..#

..#.

Вывод

5


Пример 3
Ввод

5 8

........

.##..##.

........

#......#

.######.

Вывод

34



Стоячая волна (Task2)

Профессор исследует теорию струн. Он выбрал очень длинную струну и разбил её на участки, которые пронумеровал от 1 до 10^9.

Изначально высота струны на всех участках была равна нулю. После этого произошло n квантовых событий.
Квантовое событие с номером i имело силу xi и действовало на участки струны с li-го по ri-й включительно. В результате этого события высота участка номер li
​увеличилась на xi, высота участка номер li+1 уменьшилась на xi, следующего — снова увеличилась, и так далее до участка номер ri, включительно.

Зная всю информацию о всех n событиях, профессор хочет узнать установившуюся в итоге высоту некоторых интересующих его m участков.

Формат ввода
В первой строке содержатся два натуральных числа n и mm (1≤n,m≤1000) — количество квантовых событий и количество участков, итоговая высота которых интересует профессора.

В каждой из следующих n строк содержится описание очередного квантового события — три целых числа li,ri,xi (1≤li≤ri≤10^9; 1≤xi≤1000).

В каждой из следующих m строк содержится целое число qi(1≤qi≤10^9) — номер участка, для которого требуется узнать его итоговую высоту. Номера участков приведены в возрастающем порядке.

Формат вывода
Для каждого из m запросов выведите одно целое число — высоту соответствующего участка.

Ввод
2 6
1 6 7
3 7 2

2
3
6
7
8

7
-7
9
-9
2
0
